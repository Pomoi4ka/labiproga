# Содержание

1. Исходная формулировка индивидуального задания
2. Математическая постановка задачи:
  - Дано (формулы, $x in R$ тд)
  - Найти (что находим, итоговый результат, $result in R$)
  - Способ решения (схема .. - переход к скобочному представление, шаги)
3. Контрольный пример
  - Выбор иксов
  - Рассчитываем пошагово полиномы
4. Ограничения вводимые комп.
  - Прописать диапозоны, оперделяем максимальный x
5. Огранизация ввода-вывода
  - Макеты с номерами для ссылки
  - sddd.ddd
6. Способ хранения данных
  - таблица переменных использованные для вычислений
  | тип   | имя    | назначение         | примечание | версия |
  |-------|--------|--------------------|------------|--------|
  | float | x      | входной арг        |            | 1-3    |
  | float | P, Q   | значения полиномов |            | 1-3    |
  | float | c1, c2 | коэф               | константы  | 1-3    |
7. Реализация ввода/вывода
  - средства реализации
  | библиотеки | заголовочные файлы | ввод   | вывод        | параметры   |
  |------------|--------------------|--------|--------------|-------------|
  | libc       | stdio              | scanf  | printf       | %f, %s, ... |
  | stl        | iostream           | cin >> | cout <<      |             |
  | stl        | iomanip            |        | setw         | 10, ...     |
  | stl        | iomanip            |        | setprecision | 20, ...     |
8. Представление алгоритма
  - блоксхемиы по версиям
9. Текст программы
10. Результаты работы
  - скопировать вывод
11. Выводы
  - опыт/фиксация
